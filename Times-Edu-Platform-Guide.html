02Bốn vai trò — một hệ thống

Mọi vai trò đọc cùng một nguồn sự thật. Thao tác của Quản trị lan tới các vai trò khác ngay.

Quản trị MỚITổng quan vận hành · Học viên · Gia sư · Phụ huynh · Ghép lớp · Buổi học · Học phí · Tài liệu · Nền tảng AI · Chương trình

Học viênTrang chủ · Môn học · Luyện đề · Gia sư AI · Tiến độ
Phụ huynhTổng quan · Lịch học · Tiến độ · Gia sư · Học phí · Tin nhắn

Bằng chứng "đã kết nối" — thử trên website

1

Admin → Học phí → Ghi nhận một hoá đơn, rồi mở Phụ huynh → Học phí: trạng thái đã đổi sang Đã thu.

2

Admin → Buổi học → Xếp buổi học: buổi mới hiện trong Lịch của Gia sư và Lịch của Phụ huynh.

3

Admin → Ghép lớp một học viên với gia sư: cặp hiện ở Gia sư → Học viên và Phụ huynh → Gia sư.

4

Admin → Gia sư → Duyệt hồ sơ: gia sư chuyển sang Hoạt động và nhận lớp được.

Mô hình dữ liệu dùng chung

Web STORE và mobile data/mockData.ts cùng shape: Curriculum · Student · Tutor · Parent · Session · Subject/Topic · Resource · Invoice. Mỗi export ↔ một resource API khi nối backend. Khoá Anthropic luôn ở server; client chỉ gọi backend Times Edu.

Thiết kế

04Hệ thiết kế đồng nhất

Cùng một bộ token cho web và mobile. Màu lõi: navy #1D3557, gold #B38B4D, beige #F9F5EF. Chữ: Spectral (serif) + Hanken Grotesk (sans). Mỗi vai trò có một accent riêng (Admin navy · Gia sư gold · Học viên teal · Phụ huynh đỏ rượu) bằng cách đổi một biến.

Chạy thử

05Khởi chạy

Website

Mở times-edu-platform.html bằng trình duyệt. Chọn vai trò ở màn đăng nhập, hoặc dùng nút View as (góc trên phải) để nhảy vai trò.

Mobile App

# giải nén rồi cài đặt
unzip times-edu-mobile.zip && cd mobile
npm install
cp .env.example .env        # đặt EXPO_PUBLIC_API_BASE_URL
npm start                   # bấm i (iOS) / a (Android) / w (web)
Tiếp theo

06Bước tiếp theo (production)

1

Dựng backend theo API contract; nối Auth trả { token, role }.

2

Thay từng mockData/STORE export bằng call API thật (giữ nguyên shape).

3

Mobile: lưu token bằng expo-secure-store; thêm refresh + xử lý lỗi 401.

4

Bổ sung vai trò Phụ huynh vào mobile (tái dùng module phụ huynh từ website).

5

SEO/content cho web tutor-finder tập trung chương trình quốc tế (IGCSE · A Level · IB · AP).
